# StudioScheduler – Class Attendance View Redesign Plan  
**Timestamp:** 2025-07-21_13-36

## Objective
Redesign the Class Attendance modal to display, for each student, their attendance/enrollment status for the last 4 weeks of classes, using visual flags:
- Green flag: enrolled & present
- Gray flag: enrolled & absent
- White flag with gray border: not enrolled (and not present)

## Requirements
- For each student in the class, show a row with 4 flags representing the last 4 weeks.
- The meaning of each flag:
  - Green: student was enrolled and present that week
  - Gray: student was enrolled and absent that week
  - White/gray border: student was not enrolled that week
- The 4 columns should be labeled according to context:
  - If class is in the future (this week): show Week -4, Week -3, Week -2, Week -1 (no checkbox)
  - If class is today: show Week -3, Week -2, Week -1, Today (checkbox for today)
  - If class was earlier this week: show Week -3, Week -2, Week -1, This week (no checkbox)
- Checkbox to mark presence only appears for "today" (if class is today).
- Past weeks are always read-only (no checkbox).
- Must visually distinguish between enrolled/absent/not enrolled for each week.

## Constraints
- Follow KISS, YAGNI, SRP, DRY as per .clinerules.
- No speculative features.
- Use existing domain models and DTOs where possible.
- Plan must be reviewed and approved before implementation.

## High-Level Steps
1. Analyze current attendance data structures (DTOs, backend API, frontend models).
2. Identify how to fetch attendance/enrollment for the last 4 weeks for each student.
3. Design UI changes for the modal to show 4 flags per student, with correct color logic.
4. Update logic for week labeling and checkbox visibility.
5. Ensure accessibility and clarity in the new UI.
6. Update tests/documentation as needed.

## Clarifications (2025-07-21_13-40)
- "Week" is based on calendar weeks (Monday–Sunday).
- The 4-week window is always the last 4 calendar weeks, regardless of class occurrence.
- If a class was skipped/canceled in a week, show a gray flag with a red border for that week.
- For every enrolled student, always show 4 flags: if the student joined mid-way, show white flags for weeks before enrollment.
