# StudioScheduler Schedule.Name Field Removal Plan
**Timestamp:** 2025-07-20_22-01

## Objective
Remove the `Name` field from the `Schedule` class across all solution layers. Replace any UI usage of `Schedule.Name` with `DanceClass.Name`.

## Scope
- Domain models, DTOs, database schema, migrations, repositories, services, validators, API controllers, frontend components, tests.
- Documentation and migration notes.

## Approach
1. Analyze all usages of `Schedule.Name` in codebase.
2. Identify dependencies and UI components relying on this field.
3. Plan for safe removal, ensuring no breaking changes.
4. Replace UI references with `DanceClass.Name`.
5. Update database schema and migrations.
6. Refactor affected tests and documentation.

## Risks & Considerations
- Data migration for existing records.
- UI/UX consistency.
- Impact on business logic and reporting.
- Backward compatibility.
